# green

## Requirements

- Python 3.10+
- [uv](https://docs.astral.sh/uv/)

## Installation

```bash
git clone https://github.com/your-org/green.git
cd green
uv sync
```

## Usage

```bash
uv run python main.py -i
```

### Flags

| Flag | Description |
|------|-------------|
| `-i`, `--interactive` | Launch interactive mode |
